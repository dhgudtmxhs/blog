## 글 작성 방법

`src/content/posts` 아래에 `.md` 또는 `.mdx` 파일을 추가하면 됩니다.

```md
---
title: '글 제목'
description: '글을 한 문장으로 설명합니다.'
publishedAt: 2026-09-03
tags:
  - Java
draft: false
---
```

`draft: true`로 설정한 글은 목록과 배포 결과에 포함되지 않습니다.
