배포 환경에서 컨테이너가 실행 직후 종료되었습니다. 이미 종료된 컨테이너는 기본 목록에서 보이지 않아 처음에는 실행 자체가 되지 않은 것으로 오해했습니다.

## 확인 명령어

```bash
docker ps -a
docker logs <container-id>
docker inspect <container-id>
```

로그에서는 데이터베이스 주소가 비어 있다는 메시지를 확인했습니다. 로컬 `.env` 파일에만 있던 값이 배포 환경에는 전달되지 않은 것이 원인이었습니다.

## 다음 배포를 위한 정리

- 필수 환경 변수 목록을 배포 설정에 명시합니다.
- 애플리케이션 시작 시 누락된 값을 구체적인 이름과 함께 출력합니다.
- 컨테이너의 `healthcheck`와 애플리케이션 준비 상태를 구분합니다.

명령어를 많이 실행하기보다 상태 → 로그 → 설정 순서로 범위를 좁히는 것이 빠른 해결에 도움이 됐습니다.
